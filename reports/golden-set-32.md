# مجموعه‌ی آزمون «دستیار رویا» (Golden Set — ۳۲ مورد)

> تطبیق‌داده‌شده از یک قالب عمومی ارزیابی چت‌بات، برای کسب‌وکار واقعی رویا وثوقی (مشاور/مهندس مستقل هوش مصنوعی، تورین). این مجموعه را به‌عنوان «خط‌کش» ثابت نگه دارید — بعد از هر تغییر در پرامپت (`lib/ai/prompt.ts`)، دانش (`content/knowledge/*.md`, `messages/*.json`) یا مدل (`model_config`)، دوباره اجرا کنید و با نتیجه‌ی قبلی مقایسه کنید.
