# Logo & brand assets — source of truth

**Nura** — *AI engineered for reality.* Personal brand of Roya Vosoughi
(v3, applied 2026-09-24). Every file here uses the same mark and the same
"nura" wordmark; only the background and text colour change per file.
Regenerate from `components/ui/Logo.tsx` proportions rather than
hand-editing the paths.

**The mark:** a single-stroke N in Electric Violet `#9D4EDD` whose rising
stroke ends in a Neon Cyan `#00E5FF` node — a spark of light ("nur") that is
also a network node. Never recoloured, never stretched, never split from its
node.
**Wordmark "nura":** Space Grotesk Bold, −4% tracking, lowercase, converted
to vector outlines (not live text) — renders identically everywhere, no font
install needed. Soft White `#F8F9FA` on dark, Deep Indigo `#0F0C29` on light.
Always Latin, in both English and Farsi contexts.

## Which file to use

| File | Background | Use it for |
|---|---|---|
| `nura-logo.svg` / `.png` | transparent, white text | Anywhere on Deep Indigo or another dark surface — the default |
| `nura-logo-light.svg` / `.png` | transparent, indigo text | The rare light context: printed documents, a white slide |
| `nura-logo-card.svg` / `.png` | Deep Indigo rounded card | LinkedIn banner, email signature, social previews |
| `nura-mark.svg` / `.png` | transparent | Just the mark, on your own background |
| `nura-icon.svg` / `.png` / `@256.png` | Deep Indigo rounded square | Favicon, app icon, Instagram avatar/watermark |

The site's live favicon is `app/icon.svg` (same as `nura-icon.svg`).
