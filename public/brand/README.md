# Logo & brand assets — source of truth

**Nura** — *AI engineered for reality.* Personal brand of Roya Vosoughi
(v3.1, navy & coral, applied 2026-09-24). Every file here uses the same mark and the same
"nura" wordmark; only the background and text colour change per file.
Regenerate from `components/ui/Logo.tsx` proportions rather than
hand-editing the paths.

**The mark:** a single-stroke N whose rising stroke ends in a Coral
`#E07A5F` node — a spark of light ("nur") that is also a network node. The N
is Navy `#14213D` on light and Canvas `#F5F5F7` on navy; the node is always
Coral. Never stretched, never split from its node.
**Wordmark "nura":** Space Grotesk Bold, −4% tracking, lowercase, converted
to vector outlines (not live text) — renders identically everywhere, no font
install needed. Navy `#14213D` on light, Canvas `#F5F5F7` on navy.
Always Latin, in both English and Farsi contexts.

## Which file to use

| File | Background | Use it for |
|---|---|---|
| `nura-logo.svg` / `.png` | transparent, navy | The default — any light background |
| `nura-logo-white.svg` / `.png` | transparent, white | On navy or other dark surfaces |
| `nura-logo-card.svg` / `.png` | navy rounded card | LinkedIn banner, email signature, social previews |
| `nura-mark.svg` / `.png` | transparent, navy | Just the mark, on your own light background |
| `nura-icon.svg` / `.png` / `@256.png` | navy rounded square | Favicon, app icon, Instagram avatar/watermark |

The site's live favicon is `app/icon.svg` (same as `nura-icon.svg`).
